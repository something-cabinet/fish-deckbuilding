Session 2026-08-04 (final pass): engine uses a FUNCTION-FIRST layout (spec wiki:specs/domain-layered-engine-structure). Every domain owns models/ (interfaces/types) + enums/ + constants/ + services/ (logic) + data/ (content): cards/{models,enums: card-target/card-type,constants: BUY_COST,services: targeting+effects resolver,data}, units/{models: unit,enums: team/unit-kind,services: combat,data: hero/enemy/goon defs}, battle/{models: game-state/fx-event/log-entry/pos,enums: phase/fx-kind/enemy-step-kind,constants: COLS/ROWS,services: board/state/turn}, deck/{constants: HAND_MAX/HAND_START,services: draw/shuffle}. Game use-cases are TOP-LEVEL function folders: actions/actions.service (move/attack/cast/sell/buy), commands/commands.service (PlayerCommand+executeCommand+CommandQueue), session/session.service (GameSession). shared/helpers = nid/resetIds/log/posKey/cellLabel/heroUnit/clone. ENUMS AND CONSTANTS RULE: every enum = own *.enum.ts in its domain's enums/ folder; every constant = own *.constants.ts in its domain's constants/ folder; never embedded in service files (extracted: EnemyStepKind from turn.service, HAND_MAX/HAND_START from deck.service, BUY_COST from actions.service). UI enums also own files: screen.enum.ts, drag-kind.enum.ts (components/game/). DELETED: services/ grab-bag, helpers/, root data.ts, and rules//application/ layer naming. Evolution: Angular-style → model/rules/application sub-layers → function-first. KEY LEARNINGS: (a) barrel cycles (effects↔engine, battle↔cards) come from cross-domain VALUE imports of the battle BARREL (FxKind/Phase/COLS) — import the runtime-leaf segments (battle/models, battle/enums, battle/constants) instead (D6); barrel-cycle symptom: `Module "...battle" has no exported member 'X'` on exports that DO exist; (b) TS2308 "already exported" when the same name is re-exported through two segments (EnemyStepKind in turn.service + enums barrel) — extract to one home; (c) duplicated dealDamage/drawCards/shuffle consolidated; (d) resetIds in shared helpers for deterministic SSR; (e) moves need relative import-depth fixes + JSON path shifts; (f) child-domain escalation (D8): defer vertical sub-domains until distinct responsibilities + own model; candidate = run/session becomes top-level domain when save/load lands.
