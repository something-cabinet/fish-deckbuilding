Session 2026-08-04: engine restructured to a FUNCTION-FIRST layout (spec wiki:specs/domain-layered-engine-structure, approved). Every domain owns models/ (types) + services/ (logic) + data/ (content): cards/{models,services: targeting+effects resolver,data}, units/{models,services: combat,data: hero/enemy/goon defs}, battle/{models: GameState/FxEvent/FxKind/Phase/...,services: board/state/turn}, deck/{services: draw/shuffle}. Game use-cases are TOP-LEVEL function folders, not nested in a domain: actions/actions.service (move/attack/cast/sell/buy), commands/commands.service (PlayerCommand+executeCommand+CommandQueue), session/session.service (GameSession undo/redo) — they orchestrate the whole game (Evans: one application layer per bounded context). shared/helpers = nid/resetIds/log/posKey/cellLabel/heroUnit/clone. Evolution: Angular-style → model/rules/application sub-layers (battle/application) → function-first after review of established TS/React monorepo conventions (feature folders + services/ + models/ subfolders + barrels; a global rules/ layer is the exception, not the norm). DELETED: services/ grab-bag, helpers/, root data.ts, and the rules//application/ layer naming. icons moved to src/components/game/card-icons.ts (lucide-react = presentation, was leaking into the pure engine). KEY LEARNINGS: (a) effects↔engine runtime cycle gone — root cause was cross-domain VALUE imports of the battle BARREL (FxKind/Phase/COLS); fix = import the runtime-leaf segment battle/models from cards/units/deck/shared/actions/commands/session, never the battle barrel (D5); barrel-cycle symptom: `Module "...battle" has no exported member 'X'` on exports that DO exist; (b) duplicated dealDamage/drawCards/shuffle consolidated into units/services/combat + deck/services; (c) `export *` barrels throw TS2308 "already exported" if the same name is re-exported twice (selectUnit existed in both state.service and actions.service — one home only); (d) resetIds added to shared helpers for deterministic SSR id seeds; (e) moves need relative import-depth fixes (../battle/model → ../battle/models after model→models rename) and JSON pack path shifts; (f) child-domain escalation (D7): defer vertical sub-domains until a unit has distinct responsibilities + own model; candidate = run/session becomes a top-level domain when save/load lands (run/combat state split). Verified final shape: tsc 0, 66/66 tests, next build green, zero stale services/helpers/rules/application refs.
