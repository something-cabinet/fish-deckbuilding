For the investigate/js-games prototype (and any future prototyping), use https://kenney.nl/assets for placeholder art/audio. Kenney provides free CC0 game assets (grid tiles, units, UI, SFX) that fit grid-tactics prototypes well. Prefer them over generated/custom art during prototyping.
