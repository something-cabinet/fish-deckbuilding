# Battle UI Research — FAB (Flesh and Blood) + Slay the Spire Patterns (deep dive)

Web research (2026-08-01, two passes) to inform a research-grounded redesign of the mafia-fish card-combat UI (Svelte 5 DOM + PixiJS canvas, 9×5 grid, dark pixel-art mafia underworld theme; neon-cyan=move, neon-amber=attack, signal-red=damage/debt; pure-TS engine untouchable). The prior UI (VU-Meter Desk → mafia pixel world) was scrapped pending this research. Companion to @wiki/reference/battle-ui-research-duelyst-hearthstone (referenced but missing on disk).

**Confidence key:** [OFF] = officially documented · [MOD] = modding/decompiled community spec (high trust) · [COM] = fan replication/observation (medium-low) · [SPEC] = our adaptation speculation.

## 1. FAB — full zone layout (Official: CR Ch.3, TRP §5.6)

- **15 zones** (CR 3.0.1): arms, arsenal, banished, chest, combat chain, deck, graveyard, hand, head, hero, legs, permanent, pitch, stack, weapon. Each player owns 13; stack/permanent/combat chain are shared. **Public** (12): arms, banished, chest, chain, graveyard, head, hero, legs, permanent, pitch, stack, weapon. **Private** (3): arsenal, deck, hand (3.0.4). Arena = hero + equipment + chain; piles outside it (3.0.5).
- **§5.6 geography (tournament-mandated):** hero + weapons + arsenal centered (weapons flank hero, arsenal below hero); deck-side column on one side (graveyard ABOVE deck, pitch toward center, banished BELOW deck); equipment column on the OPPOSITE side, arrayed like a body (head above chest, arms toward center, legs below chest); combat chain equally between players, links ordered side-to-side; tapped permanents rotate ~90°. Only deck and chain are strictly ordered; "sorting" piles to map the deck is illegal note-taking. **Static geography is a rules-infraction class** — that's why the table reads instantly at distance.
- **Card anatomy (CR Ch.2):** fixed corners — cost = red circle top-right (2.2.2); pitch = 1–3 socketed pips top-left (2.8.2); name top; power = yellow-spear glyph bottom-left (2.9.2); defense = grey-shield bottom-right (2.3.2); text box lower half. **Color strip along the top edge = pitch value read** (red=1, yellow=2, blue=3; 2.1.2) — survives fanning/stacking; misprint policy mandates it stay legible at distance (Oracle #13). Class frames unique; rarity common/rare/super-rare/majestic. Card size 63.5×88mm [COM].
- **Pitch/arsenal UX:** arsenal = private, max 1 card, playable from it (3.3); end of turn = set one hand card face-down there. Exists to pre-load an instant-speed response → "5 vs 4 card offensive overlap" (official B&R 2024). Pitching: face-up hand card → public pitch zone, enough to pay cost; resources expire at end of turn (3.14). Public pitch = opponents read your resource ceiling and efficiency.
- **Combat chain (CR §7):** per link: Layer → Attack → Defend → Reaction → Damage → Resolution (+Close). Defender commits any non-defense-reaction cards + public equipment; reactions interleave by priority. Damage = Power − ΣDefense, ≥1 = hit. Power/defense sums always public; hand/arsenal private — defense reactions in hand are the bluff. Digital staging: attack slides to chain (show power) → blocks accumulate as running shield total → reaction-window flash → damage resolve → hit/no-hit stamp.
- **Talishar** (React+Vite+Redux FE, PHP engine): zone components for every zone (deckZone, graveyardZone, banishZone, pitchZone, arsenalZone, heroZone, equipment zones, weaponL/R, permanents, activeLayers, cardList, zoneCounts); 3D stack of ≤12 sampled layers (desktop only; mobile drops layers), top card + count badge, click toggles `cardListFocus` popup, hover counters behind `ALWAYS_SHOW_COUNTERS`; backend sends totalPower/totalDefense per link (defense masked from attacker during defend), attackTarget, goAgain/dominate/overpower flags, hit/no-hit, `borderColor` (1=self, 2=opponent, 6=playable); colorblind-mode playmat flag exists.
- **Design philosophy (official):** "Reduce variance, One deck, Start full" (Designer: The Cost of Meaningful Decisions); 2024 B&R: Class/Talent/Hero Identity, **Empower Agency**, Every Card Counts, Paths to Victory. "FAB is a game of 4-card turn cycles; arsenal breaks it into 5-vs-4."

## 2. StS — implementation-ready specifics

- **Hand fan [COM]:** midpoint m=(n−1)/2; per-card angle θ = angleDelta·(m−i) (left CCW, right CW); pos x=sinθ·r, y=cosθ·r from center anchor; rotation = θ. Total arc ~90° for 5 cards (±30° ends), radius ≈ 1.2× card width; cap end rotation ~45°. **Rotate around bottom-center pivot** (transform-origin 50% 90%) so cards "stand" on the hand baseline. Hover: scale 1.2×, lift ~100px, 0.2s; neighbors push ±200px at 0.1s; z = hand order. Web ports use damped lerp (8–12/s) via rAF, not CSS transitions. Baseline ~20–25% up from screen bottom; deal = continuous reflow.
- **Intent icons [OFF rationale / MOD icons / COM placement]:** icon set: Attack1–4, DebuffAttack1–4, Debuff, DebuffStrong, Buff, Unknown, Sleep, Stun, Escape, Heal, Summon. **Damage tiers 0–4/5–9/10–14/15–19/20–24/25–29/30+; weapon glyph escalates dagger→broadsword→cleaver→axe→battle-axe→scythe** (War Stories). Icon floats above enemy head, **damage number directly beneath, always visible** — the whole point of killing the "Next Move" text bar. Block = shield; attack+block = sword-over-shield; debuff = green swirl; mega-debuff = purple; buff = blue flame; unknown = "?". Icons swap instantly at turn start; numbers pop. ~1 icon-height above sprite top (60–80px @1080p).
- **Card anatomy [MOD]:** art 250×190 in-hand / 500×380 portrait (25:19, BaseMod modding standard); rendered card ≈245×340 @1080p. Cost gem top-left circle; title banner rarity-colored (common grey, uncommon blue, rare gold — decompiled setDisplayRarity); art band 25:19; description bottom ~30% with colored DynamicVars (damage orange, block blue, magic green) + upgrade previews. Distinct frames per type/rarity; title font FreeType, 2.25px grey border, 3px black shadow, gamma 0.9.
- **HUD [COM]:** top bar gold + potions + map + deck-view icon top-right with live count badge; draw pile bottom-left, discard bottom-right, stacked with counts, click opens contents, hover previews top card; DeckView = full-list overlay, hover-zoom, right-click inspect; relics right-edge vertical column; energy = single orb (counter, not pips) left of hand, default 3, dims when depleted, "Not enough energy" toast on failed play.
- **Feedback [COM/industry]:** floating numbers spawn same-frame, float up + fade 0.6–1.2s; crit 150–200% size yellow/orange; damage-taken red larger; block/miss grey-blue small; 20–40px random offset; merge hits within 100–200ms. Buff/debuff icons ~32px row with stack counts, tooltips (green=debuff, blue=buff). Card play drag toward play zone, resolve tweens to discard; **streak/afterimage trails on draw & discard** (Cloudfall); animations never block input — cast before draw completes.
- **Turn flow:** End Turn anchored bottom-right of hand, disabled during resolution; auto-discard hand + drain energy. Reward screen: 3-card choice, rarity-bordered, hover-zoom, skip always. Map: dotted-line nodes, only adjacent clickable.
- **Grid adaptation — Into the Breach precedent [OFF]:** telegraph-on-grid = **attack trail + red target-tile highlight**; melee = adjacent tile, projectile = straight line to first obstruction, artillery = any tile in line. Dev credo: "sacrifice cool ideas for clarity every time." Crowding solutions for multi-unit 9×5: (a) per-unit badge only when the unit acts this turn; (b) **tile-level overlays** (red boxes + arrows) for ranged/AoE — removes per-unit icon stacks; (c) stacked icons offset vertically; (d) keep telegraph color separate from damage color — amber attack tint on tiles, signal-red stays damage/debt. Only ~3 threat types (move/attack/debuff) → keep glyph set tiny (3 weapon tiers max).

## 3. Transferable patterns for the 9×5 mafia-fish game

1. **Static zone geography [FAB]:** zones are fixed cells; only cards/units move (tween). Enemy intent/telegraph zone above grid; economy pillar per side (deck→pitch→graveyard vertical, mirroring FAB's deck column); board center = arena. Reserve outer columns for piles so no zone overlaps the action [SPEC].
2. **Enemy telegraphing = readable dialogue [FAB chain + ItB]:** stage enemy attacks as 5-step conversation — power slides onto chain, block commitment accumulates as running shield number, reaction-window flash, hit/no-hit stamp. On grid: attack trail + amber target-tile tint + per-unit intent badge with precise number.
3. **Fixed corner anatomy [FAB]:** cost top-right (red), pitch/resource pips top-left, power bottom-left (amber), defense bottom-right (grey) — location-based reading.
4. **Top-edge color strip as resource read [FAB]:** strip = fuel/cost tier, readable in a fanned hand and on piles.
5. **Pitch/arsenal as resource telegraph [FAB]:** enemy pitch cell fills with public pips (resource ceiling); arsenal shows occupied/empty with flip animation when burned — the enemy's "pre-loaded response" tell.
6. **Hand fan geometry [StS]:** bottom-center pivot, ~90° arc, 1.2× radius, 0.2s hover (scale 1.2×, lift 100px), damped lerp reflow.
7. **Playable-glow affordance [StS]:** amber/cyan glow only when affordable; dim when not; "not enough energy" toast; distinct armed vs finished end-turn states.
8. **Actionable-number feedback [StS]:** floating damage 0.6–1.2s float-fade, 20–40px jitter, merge within 100–200ms; block = shield badge with number; crit emphasis.
9. **Pile UX [StS/Talishar]:** deck/discard stacks with counts, click → full-list popup, hover preview top card; DeckView moment = interest/debt preview.
10. **Glanceability budget [StS]:** one glance answers "Can I act? What threatens? What will I lose?" — static geography + always-visible intent numbers + fixed corners.
